Это обучающий просмотрщик исходников проекта SchoolExpensesDemo.

Слева — список модулей Delphi. Код каждого модуля разбит на блоки (классы, методы, секции uses, interface и т.п.). При наведении на блок подсвечивается весь диапазон строк и всплывает подсказка: зачем этот код нужен и как работает.

Начните с uDb — подключение к базе, затем uRepositories → uServices → uMainData → формы и фреймы.
